🐍 Snake Water Gun Game (Python)
This is a simple Snake Water Gun game built using Python.
The game is played between the user and the computer, where each chooses one option: Snake, Water, or Gun.
The winner is decided based on predefined rules.
📌 Rules
Snake drinks Water → Snake wins
Water drowns Gun → Water wins
Gun kills Snake → Gun wins
Same choice → Draw
🛠️ Technologies Used
Python
Random module
▶️ How to Run
Make sure Python is installed on your system
Clone this repository
Run the file:
Copy code
